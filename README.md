# CSC311 GUI Basics

## Run the app

From the project root:

```bash
cd "/Users/m.faseeh10/Downloads/Advanced Programming/CSC311_GUI_Basics"
./mvnw javafx:run
```

## UI behavior

- **Option 1**: Shows FC Barcelona recent performance stats in a table.
- **Option 2**: Shows the same stats as a bar chart.
- **Change Image**: Toggles between two FC Barcelona-related images.
